CRM-Style Lead System
📌 Project Overview
This project is an automated CRM-style lead management system designed to capture, organize, and track leads efficiently using Excel and email automation.

It helps businesses respond faster, avoid missed leads, and improve conversion rates through streamlined workflows.

🚨 Problem
Manual lead handling in spreadsheets and email leads to:

Slow response time
Missed follow-ups
Disorganized data
Lost sales opportunities
💡 Solution
An automated CRM-style system that:

Captures leads automatically
Organizes data in Excel
Sends instant and scheduled email follow-ups
Tracks lead status in real-time
⚙️ Tools Used
Excel / Google Sheets
Zapier (Automation)
Gmail / Email API
CRM logic workflow design
🔄 Workflow
Lead is captured from form/email/source
Data is automatically stored in Excel sheet
Lead status is categorized (New, Contacted, Follow-up, Closed)
Automated email is triggered based on stage
System tracks progress for each lead
📊 Result
Faster response time
Organized lead tracking
Reduced manual work
Higher conversion efficiency
